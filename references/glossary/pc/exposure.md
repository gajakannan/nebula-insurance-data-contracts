# Exposure Terms

## Insurable Object

An object, property, vehicle, operation, interest, or location that may be insured.

## Insurable Object Type

A classification of the kind of insurable object represented.

## Insurable Object Classification

A durable classification used to organize insurable objects for underwriting, rating, reporting, or analytics.

## Classification Scheme

The business scheme or grouping from which an insurable object classification is drawn.

## Exposure

The measurable risk basis associated with a policy, coverage, claim, submission, underwriting, or analytical context.

## Exposure Identifier

A stable canonical identifier for an exposure record.

## Exposure Type

A classification of the kind of risk basis represented.

## Exposure Basis

The basis used to measure exposure.

## Exposure Quantity

The measured amount of exposure.

## Exposure Unit

The unit of measure used for exposure quantity.

## Rating Territory

A geographic, regulatory, or business territory used in rating or risk evaluation.

## Geographic Location

A canonical location reference that can be associated with an exposure, insurable object, policy, claim, or other business context.

## Vehicle Exposure

Vehicle-specific exposure attributes linked to a canonical exposure.

## Vehicle Use

A classification of how a vehicle is used for insurance risk evaluation.

## Vehicle Class

A classification of a vehicle for underwriting, rating, reporting, or analytics.

## Garaging Location

The location where a vehicle is ordinarily kept or principally located.

## Radius

A classification or measure describing the operating radius for a vehicle exposure.

## Stated Value

The value stated for a vehicle or other insured item when used as an exposure or coverage basis.

## Property Exposure

Property-specific exposure attributes linked to a canonical exposure.

## Property Use

A classification of how property is used for insurance risk evaluation.

## Occupancy Type

A classification describing occupancy of a property.

## Construction Type

A classification describing the construction characteristics of a property.

## Protection Class

A classification used to represent fire protection, emergency response, or other protective context for a property exposure.

## Building Value

The monetary value associated with the building portion of a property exposure.

## Contents Value

The monetary value associated with contents for a property exposure.

## Workers Compensation Exposure

Workers compensation-specific exposure attributes linked to a canonical exposure.

## Governing Class

The classification treated as the primary workers compensation classification for a risk context.

## Job Duty Description

A business description of work duties associated with a workers compensation exposure.

## Payroll Amount

Payroll used as an exposure measure for workers compensation risk.

## Employee Count

The number of employees associated with a workers compensation exposure.

## Full Time Equivalent Count

The employee count normalized to a full-time equivalent basis.

## Payroll Period

The date range for payroll used in a workers compensation exposure.
