# Property and Casualty Contracts

Canonical Property and Casualty insurance data contracts.

## Contract Areas

- `core/`: party, roles, relationships, account, and agreement concepts.
- `submission/`: submission intake, participation, risk, assessment, document, and lifecycle concepts.
- `policy/`: policy, term, party role, lifecycle event, transaction, and document concepts.
- `coverage/`: product, coverage, policy coverage, limit, and deductible concepts.
- `exposure/`: insurable object and exposure concepts.
- `claims/`: claim, claim event, coverage, party role, and document concepts.
- `financial/`: policy and claim financial transaction concepts.
- `reference-data/`: location, line of business, transaction type, and lifecycle reference data.
