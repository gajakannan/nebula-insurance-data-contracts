# Patterns

Reusable modeling patterns for canonical insurance data contracts.

## Property and Casualty

- `pc/account-pattern.md`
- `pc/party-role-pattern.md`
- `pc/submission-lifecycle-pattern.md`
- `pc/policy-lifecycle-pattern.md`
- `pc/policy-coverage-pattern.md`
- `pc/claim-lifecycle-pattern.md`
- `pc/exposure-pattern.md`
- `pc/financial-transaction-pattern.md`

Patterns describe the shape of common modeling problems. The cross-cutting conventions that govern every contract (identifiers, SCD2, classifications, codesets, currency, etc.) live as ADRs under `references/design-decisions/`. See `references/design-decisions/README.md` for the index.
