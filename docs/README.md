# Documentation

Project documentation, examples, roadmap notes, and usage guidance.

## Contents

- `authoring-guide.md`: contract authoring workflow, naming rules, ODCS expectations, versioning, status lifecycle, and contribution boundaries.
- `repository-and-architecture.md`: full repository structure, medallion architecture data flow, and P&C operating lifecycle diagrams.
- `tutorial/`: layered data flow tutorial — row-level walkthroughs of how P&C policies move from source systems through Bronze, canonical Silver, Fabric artifacts, and Gold. Includes parts 01-03 for one Acme Manufacturing new-business-through-cancellation scenario, `04-renewal.md` as a companion renewal scenario focused on policy and term identity, and `05-gold-projection.md` for consumer projections.
- `contract-inventory.md`: generated navigation surface covering every canonical contract by kind, Spark schema, version, status, description, and ADR back-links. Regenerated by `scripts/generation/generate-contract-inventory.py`; do not edit by hand.
- `review-checklist.md`: structured checklist for reviewing a canonical-contract pull request. Codifies the canonical and Fabric drift validators, the human-judgment gates, the status-promotion review path, and the Fabric blast-radius trace.
- `roadmap/pc-contract-backlog.md`: suggested first Property and Casualty contract set and milestone scope.
- `examples/`: examples and usage walkthroughs.
